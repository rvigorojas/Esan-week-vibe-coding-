# 🍱 Temporizador Hora de Almuerzo para VS Code (Python)

Extensión para Visual Studio Code desarrollada en Python que muestra un reloj en la barra de estado para controlar el tiempo restante de tu almuerzo.

## 🚀 Características
- Temporizador dinámico en la barra de estado.
- Notificaciones al iniciar y terminar el tiempo.
- Opción para cancelar el temporizador antes de tiempo.

## 📦 Instalación
1. Requisitos: Tener instalado Python y el paquete `vscode`.
