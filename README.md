# 🍱 Hora de Almuerzo para Visual Studio Code

[![GitHub Release](https://img.shields.io/github/v/release/TU_USUARIO/vsc-hora-almuerzo-python?color=green)](https://github.com/TU_USUARIO/vsc-hora-almuerzo-python/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Una extensión liviana para Visual Studio Code escrita en Python que te ayuda a controlar tu tiempo de descanso directamente desde la barra de estado.

---

## 📸 Demostración

![Demo de la extensión](https://raw.githubusercontent.com/TU_USUARIO/vsc-hora-almuerzo-python/main/demo.gif)

---

## ✨ Características

- ⏱️ **Reloj en tiempo real:** Muestra los minutos y segundos restantes en la barra de estado.
- 🔔 **Notificaciones inteligentes:** Alerta cuando tu tiempo de almuerzo ha finalizado.
- ⚙️ **Personalizable:** Define la duración del almuerzo en minutos cada vez que lo inicias.
- 🛑 **Control manual:** Cancela o detén el temporizador en cualquier momento.

---

## 🚀 Cómo instalar (Usuario final)

### Opción A: Archivo de instalación rápida (.vsix)
1. Ve a la sección de **[Releases / Lanzamientos](https://github.com/TU_USUARIO/vsc-hora-almuerzo-python/releases)** en este repositorio.
2. Descarga el archivo `hora-almuerzo-1.0.0.vsix`.
3. Abre VS Code, ve a la pestaña de **Extensiones** (`Ctrl+Shift+X`).
4. Haz clic en los tres puntos `...` arriba a la derecha y selecciona **Instalar desde VSIX...** (*Install from VSIX...*).
